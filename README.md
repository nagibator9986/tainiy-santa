# Тайный Санта

Новогодний сайт для обмена подарками в компании, офисе или семье.
Стилистика — «почта Деда Мороза»: ночное небо со снегом, санями и гирляндой,
конверты с сургучом, марки, анонимные телеграммы.

**Flask + SQLite**, без сборки фронтенда и без внешних сервисов.

## Как это работает

1. **Организатор** заходит в `/admin`, вписывает участников (можно списком),
   отмечает пары и семьи, которые не должны дарить друг другу, и задаёт дату,
   бюджет и место.
2. Каждому участнику организатор отправляет **личную ссылку**. При первом
   входе участник придумывает PIN: после этого в конверт не заглянет никто,
   даже организатор.
3. Участник пишет **письмо Деду Морозу**: что хочет получить, чего дарить не
   надо и что полезно знать (размеры, цвета, аллергии). Дописывать можно до
   самого праздника.
4. Организатор нажимает **«Запечатать конверты»**. Участник ломает сургучную
   печать и видит, кому дарит, а заодно письмо этого человека.
5. Через **анонимный телеграф** Санта может спросить подопечного, например
   про размер варежек, и тот ответит, не зная, кто спрашивает.

## Умная жеребьёвка

Алгоритм ищет **одну общую цепочку** на всех (гамильтонов цикл):
`А → Б → В → … → А`. Так никто не дарит «в ответ» тому, кто дарит ему.

- Исключения («Аня и Борис — пара») и группы («семья Ким») — запрещённые рёбра.
- Поиск идёт в глубину с эвристикой Варнсдорфа и перезапусками, поэтому
  справляется с плотными ограничениями.
- Если одной цепочки не существует, берётся допустимое распределение
  (паросочетание, алгоритм Куна) с минимумом взаимных пар.
- Если распределить нельзя вообще, организатор видит понятную причину,
  например: «У участника „Аня“ нет ни одного возможного получателя».
- Случайность берётся из `random.SystemRandom`.

Код: [`santa/draw.py`](santa/draw.py), тесты: [`tests/test_draw.py`](tests/test_draw.py).

## Тайна

- В админке нет ни одной страницы и ни одного поля, где видны пары.
  Организатор видит только отметки: придуман ли PIN, есть ли письмо,
  вскрыт ли конверт, готов ли подарок.
- В базе пары и переписка **зашифрованы** (Fernet, ключ берётся из
  `SECRET_KEY`). Даже открыв файл базы, их не прочитать.
- Конверт открывается только по PIN участника. После 5 ошибок вход
  закрывается на 15 минут.
- Если организатор сбросит PIN, участник увидит отметку о сбросе. Время
  вскрытия конверта тоже видно, так что подглядывание не пройдёт незаметно.

## Запуск локально

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
ADMIN_PASSWORD=secret .venv/bin/python wsgi.py   # http://127.0.0.1:5077
```

Без `ADMIN_PASSWORD` при первом входе в `/admin` сайт попросит придумать пароль.

Тесты:

```bash
.venv/bin/pip install pytest
.venv/bin/python -m pytest -q
```

## Переменные окружения

| Переменная       | Зачем                                                                     |
|------------------|---------------------------------------------------------------------------|
| `ADMIN_PASSWORD` | пароль организатора (иначе — мастер первого запуска)                       |
| `DATA_DIR`       | где лежат `santa.sqlite3` и `secret_key` (по умолчанию `./instance`)       |
| `SECRET_KEY`     | ключ сессий и шифрования; если не задан, создаётся файл в `DATA_DIR`      |
| `APP_TIMEZONE`   | часовой пояс праздника, по умолчанию `Asia/Almaty`                        |
| `COOKIE_SECURE`  | `1` — cookie только по HTTPS (на проде)                                   |
| `PUBLIC_URL`     | адрес сайта для личных ссылок, если он отличается от адреса запроса        |

> `DATA_DIR` должен лежать на постоянном диске. Если потерять `secret_key`,
> конверты больше не откроются, и жеребьёвку придётся провести заново.

## Деплой на Railway

В репозитории есть `Dockerfile` и `railway.json` (healthcheck `/healthz`).

1. Создайте сервис из этого репозитория.
2. Добавьте **Volume** с точкой монтирования `/data`. Без него база будет
   стираться при каждом деплое.
3. Задайте переменные `ADMIN_PASSWORD` и `COOKIE_SECURE=1`.
4. Сгенерируйте домен. Перед праздником можно сделать копию: файлы лежат в
   томе `/data`.

## Структура

```
santa/
  __init__.py     фабрика приложения, секрет, healthcheck
  draw.py         алгоритм распределения
  db.py           SQLite: схема, настройки
  crypto.py       шифрование пар и переписки
  models.py       участники, пары, переписка
  public.py       главная и личный конверт
  admin.py        книга почтмейстера
  templates/      Jinja-шаблоны (сцена неба и деревни — inline SVG)
  static/         один CSS, один JS, фавикон
tests/            алгоритм + сквозные сценарии
```
